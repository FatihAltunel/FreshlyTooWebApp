Project: FreshlyToo Mobile App Landing Page (v2 Design System)
Role: UI/UX Designer
Objective: Implement the refined brand design language from the professional handoff package.

#### 1. Color Tokens & Theme
* **Main Background:** Warm Light Cream (`#faf7ef`) for an organic, premium feel.
* **Primary Text / Dark Tone:** Deep Charcoal / Forest Black (`#14251a`).
* **Accents:** Fresh Eco-Green (`#15803d` / `#14532d` / `#dcfce7` highlights).

#### 2. Typography
* **Font Family:** `Instrument Sans` (Primary sans-serif) and `Instrument Serif` (Editorial accent headings) via Google Fonts.
* **Hierarchy:** Bold weights (600/700) for impactful statements, clean readable tracking for body copy.

#### 3. Layout & Components
* **Real App Mockups:** Embed actual screenshots (`home.png`, `map.png`, `detail.png`, `pickup-qr.png`) inside phone frames instead of abstract illustrations.
* **Responsive Mobile-First:** Ensure fluid spacing, smooth accordions for FAQs, and a sticky navigation bar with a clear TR/EN language toggle.
